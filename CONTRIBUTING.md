# Contributing

Anyone is welcome to contribute to this project.
Please make sure to follow these steps thoroughly to contribute :

1. **Fork the repository:** Click the Fork button on GitHub to create your copy.

2. **Clone your fork:**
   ```bash
   git clone https://github.com/your-username/your-fork.git
   ```

3. **Create a branch for your feature:**
   ```bash
   git checkout -b feat/your-feature
   ```

4. **Set up the environment:** Follow the setup instructions in the README.

5. **Use clear commit messages:**
   - `feat:` – New feature
   - `fix:` – Bug fix
   - `docs:` – Documentation update
   - `refactor:` – Code restructuring

6. **Submit a Pull Request (PR):**

   Include:
   - Description of the changes
   - References to issues (e.g., Closes #12)
   - Screenshots or examples (if applicable)

7. **Participate in the code review:** Be collaborative and responsive.
